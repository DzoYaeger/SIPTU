# SIPTU ULTRA mobile illustrations

Initial Fluent Enterprise illustration set for the Flutter mobile app.

| Asset | Intended use |
| --- | --- |
| `onboarding-workflow.png` | Onboarding and first-run explanation of digital requests |
| `empty-history.png` | Empty state for request/history lists |
| `status-approved.png` | Successful submission or approved request state |

These are raster illustrations with transparent backgrounds. Functional UI icons should remain vector-based through the app icon system.
